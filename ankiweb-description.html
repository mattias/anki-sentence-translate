Sentence Translate translates the Japanese example sentence on your cards into natural English and puts the English equivalent of the target word in bold, so you see at a glance what the word means in this sentence. Made for mining cards (Kiku, Lapis and similar note types); field names are configurable.

Example: 竜は左目がつぶれてる。 → The dragon has its left eye crushed.

Features

  • Browser menu: Cards > Translate Sentence to English (Ctrl+Alt+T) for the selected notes. Reads Sentence and Expression and writes SentenceTranslation.
  • Editor button EN (Ctrl+Shift+T) for the note you are editing or adding.
  • Choose the engine: the Claude API (best quality), a local Ollama model (free, offline) or any OpenAI-compatible server such as LM Studio.
  • Every answer is checked: it must contain exactly one bold word or phrase, in English. Otherwise the model is asked again, and a note that still fails is left unchanged.
  • Safe: an existing translation is never replaced without asking, Sentence is never changed, and one undo reverts a whole browser run.
  • Background translation with progress and cancel. Translated notes are tagged translated.

Getting started

  1. Install the add-on and restart Anki.
  2. Open Tools > Add-ons > Sentence Translate > Config. For Claude, set "ENGINE": "claude" and paste your API key from console.anthropic.com into CLAUDE_API_KEY. For a local model, set "ENGINE": "ollama" and OLLAMA_MODEL to a model from ollama list.
  3. Run Tools > Sentence Translate: test engine to check the settings.
  4. Select 3-5 notes in the card browser and run Cards > Translate Sentence to English. Check the result before running it on many notes.

Which engine?

Measured on 14 real mining sentences, cost per 1000 notes with the Claude API:

  • claude-opus-5-5 (default): about $3.90. Best with names, wordplay and words whose meaning depends on the context.
  • claude-sonnet-5-5: about $2.10. Very close to Opus.
  • claude-haiku-5-5: about $0.11. Good for plain sentences, but bolds the wrong word more often.

The Claude API is billed separately from a Claude.ai subscription; you buy credits in the Anthropic Console and can set a monthly limit there. Local 8-12B models (Qwen3, Gemma) are free and fine for short, simple sentences, but make more mistakes with names, long sentences and which word to bold.

Troubleshooting

  • "CLAUDE_API_KEY is empty" or HTTP 401: check the key in the add-on config, and that ENGINE is claude.
  • HTTP 400 about credit balance: buy credits in the Anthropic Console.
  • "cannot reach http://127.0.0.1:11434": Ollama is not running. Start it, or switch ENGINE.
  • Notes are skipped: the note needs Sentence, Expression and SentenceTranslation (or the field names you set in the config), and a sentence.
  • Some notes failed: the model did not bold exactly one English word after several tries. Run those notes again or translate them by hand. Details are printed to the debug console.

Privacy

The sentence, target word, its reading and dictionary meaning are sent to the engine you choose: to Anthropic for Claude, or to your own computer for Ollama and LM Studio. Your API key is stored only in Anki's add-on config on your computer.
