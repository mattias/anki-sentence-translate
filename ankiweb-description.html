Sentence Translate translates the example sentence on your cards into your language and puts the translation of the target word in bold, so you see at a glance what the word means in this sentence. Made for mining from Yomitan (Kiku, Lapis and similar note types). Languages and field names are configurable.

Example: 竜は左目がつぶれてる。 → The dragon has its left eye crushed.

Features

  • Automatic for new cards: cards you add from Yomitan (or the Add window) are created at once and translated in the background. A failed translation never blocks the card.
  • Older cards too: Cards > Translate Sentence (Ctrl+Alt+T) in the card browser translates the selected notes, with progress, cancel and one undo for the whole run.
  • Editor button (Ctrl+Shift+T) for the note you are editing or adding.
  • Any language pair: source language auto-detect or chosen, target language English, Swedish, Russian, Spanish and more.
  • Choose the engine: Claude API (best quality), Google Gemini API (free tier), a local Ollama model (free, offline) or any OpenAI-compatible server such as LM Studio.
  • Every answer is checked: it must contain exactly one bold word or phrase in the target language. Otherwise the model is asked again, and a note that still fails is left unchanged.
  • Safe: an existing translation is never replaced without asking, and Sentence is never changed. Rate limits are retried; a used-up daily quota is reported clearly.
  • A settings window with a Test connection button. No JSON editing needed.
  • New: pictures, fully local. Cards > Add picture of the word (Ctrl+Alt+P) draws a small picture of the target word for notes without one, such as sentences from books. A local text model (Gemma 4 12B in Ollama) describes the word's meaning in the sentence and FLUX.1 [schnell] draws it in about 5 seconds per picture. Words that cannot be pictured get the sentence's scene instead. One-time setup from Tools > Sentence Translate: set up pictures (about 25 GB, needs an NVIDIA GPU and Ollama).

Getting started

  1. Install the add-on and restart Anki.
  2. Open Tools > Sentence Translate settings... (or Config in the add-ons list).
  3. Choose the engine and paste its API key: Claude from console.anthropic.com, Gemini from aistudio.google.com/apikey. For Ollama, enter a model from ollama list.
  4. Choose Translate from (Auto-detect is fine) and Translate into, check the field names, click Test connection and Save.
  5. Add a card from Yomitan as usual, or select 3-5 notes in the card browser and press Ctrl+Alt+T. Check the result before translating many notes.

Which engine?

Measured on 14 real Japanese mining sentences into English, cost per 1000 notes:

  • claude-opus-5-5 (default): about $3.90. Best with names, wordplay and words whose meaning depends on the context.
  • claude-sonnet-5-5: about $2.10. Very close to Opus.
  • gemini-3.6-flash: free within Gemini's free tier (about $0.37 on the paid tier). Close to Sonnet.
  • gemini-3.5-flash-lite: free within the free tier (about $0.20 paid). Good for plain sentences, misses more nuance.
  • claude-haiku-5-5: about $0.11. Good for plain sentences, but bolds the wrong word more often.

Gemini's free tier has a daily request limit per model, and it differs between models (some allow only about 20 requests a day). The Claude API is billed separately from a Claude.ai subscription; you buy credits in the Anthropic Console and can set a monthly limit there. Local 8-12B models (Qwen3, Gemma) are free and fine for short, simple sentences, but make more mistakes with names, long sentences and which word to bold.

Troubleshooting

  • Test connection fails with HTTP 401 or 403: check the API key and that the right engine is selected.
  • "The API's quota is used up": Gemini's daily free limit for that model is reached. Wait until the next day, choose another Gemini model, or switch engine.
  • HTTP 400 about credit balance (Claude): buy credits in the Anthropic Console.
  • "cannot reach http://127.0.0.1:11434": Ollama is not running. Start it, or switch engine.
  • New cards are not translated: check that Translate new notes automatically is on and that the field names match your note type. The card needs a sentence, a target word and an empty translation field.
  • Some notes failed: the model did not bold exactly one word after several tries. Run those notes again or translate them by hand. Details are printed to the debug console.

Privacy

The sentence, target word, its reading and dictionary meaning are sent to the engine you choose: to Anthropic for Claude, to Google for Gemini, or to your own computer for Ollama and LM Studio. API keys are stored only in Anki's add-on config on your computer.
